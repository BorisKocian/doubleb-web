# Footer

Pätička: znak s jednou vetou o štúdiu, odkazy na stránky, kontakt a vstup do skrytého terminálu.

- Obal `db-footer` s hornou čiarou `line`, mriežka `db-footer__grid` (na mobile pod sebou).
- Nadpisy stĺpcov v štýle `label` a `muted`, malými písmenami. Odkazy v `ink-soft`, pri prejdení myšou `ink`.
- Do pätičky patrí obchodné meno a sídlo (DoubleB dev s.r.o., Žilina) a ďalšie povinné údaje (IČO), keď budú na webe.
- Spodný riadok `db-footer__bottom`: copyright vľavo, vpravo `~ $` v `accent` s pozvánkou do Terminal. Na mobile len odkaz, bez klávesovej skratky.
- E-mail v ukážke je zástupný.
