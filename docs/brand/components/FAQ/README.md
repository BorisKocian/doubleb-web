# FAQ

Otázky a odpovede ako rozbaľovacie riadky; bodka pred otázkou sa pri otvorení zmení na zelenú paličku.

- Obal `db-faq`, každá otázka je natívny `details` so `summary`. Funguje bez JavaScriptu aj klávesnicou.
- Otázka: Schibsted Grotesk 22 px, tučná, `ink`. Značka pred ňou: bodka v `code-bar`, pri prejdení myšou palička, otvorená palička v `accent`.
- Odpoveď `db-faq__a` v `ink-soft`, najviac 720 px, zarovnaná pod text otázky. Dve až tri vety, prvá odpovedá priamo.
- Otázky píšte tak, ako by ich položil klient. Patria sem obavy, ktoré by inak ostali nevyslovené (zastupiteľnosť, vlastníctvo kódu, rýchla cena).
- Texty v ukážke sú návrh.
