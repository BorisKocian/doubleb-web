# Quote

Citát klienta: veľký riadok modulu, citát v Schibsted Grotesk a podpis v JetBrains Mono.

- Obal `db-quote` (najviac 880 px), nad citátom `db-row db-row--lg` s jedným prvkom v `accent`.
- Citát v `blockquote`: Schibsted Grotesk 28 px, tučná, `ink`. Bez úvodzoviek a bez ikony úvodzoviek.
- Podpis vo `figcaption`: meno, rola a firma v štýle `label` a `muted`.
- Len skutočné citáty so súhlasom klienta, doslovne. Nikdy neskracovať tak, aby sa zmenil význam, a nikdy nevymýšľať. Ukážka obsahuje zástupný text v hranatých zátvorkách.
- Najviac jeden citát na sekciu.
