# Lists

Zoznamy v texte: odrážka je palička modulu, číslovaný zoznam má čísla v JetBrains Mono.

- `db-ul`: odrážka je palička v `code-bar`, vertikálne vycentrovaná na prvý riadok textu. Text v `ink` alebo `ink-soft`.
- `db-ul db-ul--accent`: paličky v `accent`. Len pre zoznam toho, čo klient dostane alebo čo garantujeme, najviac raz v sekcii.
- `db-ol`: čísla „01“, „02“ v JetBrains Mono 13 px a `accent`. Pre poradie krokov.
- Odrážky sú vždy paličky, nikdy bodky ani znaky písma (•, –).
- Položka je krátka veta bez bodky na konci. Ak má zoznam viac ako šesť položiek, rozdeľte ho alebo zvážte tabuľku.
