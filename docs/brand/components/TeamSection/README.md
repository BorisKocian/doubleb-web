# TeamSection

Dve karty ľudí so zámerne rovnakým zoznamom a pointa pod nimi: keď jeden chýba, druhý pozná celý projekt.

- Obal `db-team` (dva stĺpce, na mobile pod sebou), karta `db-person` s rámikom `line`.
- Fotka v `db-avatar` (120 × 120 px, `radius-md`, `object-fit: cover`). Kým fotky nie sú, avatar tvoria tri riadky modulu.
- Meno v štýle `h2`, zoznam `db-ul`. Zoznamy oboch ľudí sú rovnaké, v tom je vtip aj dôkaz. Nepridávať titulky typu CEO alebo CTO.
- Pointa pod kartami v štýle `h2`, najviac 760 px: zameniteľnosť je jediné tvrdenie, ktoré sólista ani veľká agentúra nemôže zopakovať.
- Na hlavnej stránke môže túto sekciu otvárať StudioReveal.
