# SectionHeader

Začiatok každej sekcie: číslovaný štítok s čiarou, nadpis a jedna až dve vety úvodu.

- Štítok: `db-eyebrow` (riadok modulu, text v štýle `label` a `muted`, čiara `line` do konca obsahu). Formát textu „01 / názov sekcie“, malými písmenami.
- Nadpis v štýle `h1` a `ink`, najviac 820 px široký. Veta s tvrdením, nie názov kategórie („Ako pracujeme“ patrí do štítku).
- Úvod v štýle `lead` a `ink-soft`, najviac 760 px.
- Medzi sekciami je `space-5`, medzi hlavičkou a obsahom `space-4`.
