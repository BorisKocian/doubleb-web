# Logos

Znak DoubleB: riadky bodiek a paličiek, v každom riadku jeden prvok v značkovej zelenej (#00FF00, token `accent`), ostatné biele, na čiernom pozadí (`bg` v tichom režime).

- `doubleb-znak.jpg`: pôvodný súbor 1600 × 1600 px, JPG na čiernom pozadí. Použiteľný na náhľady a sociálne siete, nie na web ani tlač.
- Chýba: SVG verzia na čiernu a na zelenú plochu (v hlasnom režime sú biele prvky čierne a zelené prvky čierne alebo vynechané, rozhodnúť pri prekreslení).
- Znak nikdy neprekresľovať od oka a nemeniť jeho farby mimo tokenov.
